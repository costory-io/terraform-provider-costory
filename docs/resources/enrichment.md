# costory_enrichment (Resource)

Manages one Costory enrichment from a YAML file. The file is the customer document, with `conditions` written in CEL and `targetColumns` as a map from column to `{ mode }`, in column order. Applying stores the document as a draft; `costory_enrichments_publish` makes the drafts live in one transaction. Destroying drafts the removal.

## Example Usage

```terraform
terraform {
  required_providers {
    costory = {
      source  = "costory-io/costory"
      version = ">= 0.1.0"
    }
  }
}

variable "costory_api_token" {
  type        = string
  description = "Costory API key of an organization admin."
  sensitive   = true
}

provider "costory" {
  token = var.costory_api_token
}

# One resource per YAML file in ./enrichments. Applying stores drafts;
# costory_enrichments_publish makes them live.
resource "costory_enrichment" "all" {
  for_each = fileset("${path.module}/enrichments", "*.yaml")

  name = trimsuffix(each.value, ".yaml")
  file = "${path.module}/enrichments/${each.value}"
}
```

## Example mapping file

`enrichments/namespace.yaml`: rows whose `cos_namespace` is `payments` get `owner_org = Payments`.

```yaml
# Maps a Kubernetes namespace to the team that owns it.
name: namespace
description: Owner of each namespace
keyField: cos_namespace # billing column read as the key
priority: 2 # lower runs first when several enrichments fill the same columns
conditions: input.cos_cluster_name != null # optional, CEL
targetColumns: # filled columns, in order
  owner_org: { mode: merge } # merge: only fills empty values; replace: overwrites
entries:
  - key: payments
    then: { owner_org: Payments }
  - key: fluent-bit
    when: { start: "2026-01-01" } # optional, YYYY-MM-DD
    then: { owner_org: SRE }
```
